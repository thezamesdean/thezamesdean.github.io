개인정보처리방침

이 도구는 YouTube 채널 옛날사람들TV 소유자 본인만 사용합니다.

  • YouTube Data API 권한은 채널 소유자의 영상 업로드·예약·썸네일 설정에만 씁니다.
  • 다른 사람의 개인정보나 Google 계정 데이터를 수집·저장·공유하지 않습니다.
  • 인증 토큰은 소유자의 컴퓨터에만 저장되며 외부로 전송하지 않습니다.
  • Google 계정 설정의 '타사 액세스'에서 언제든 권한을 해제할 수 있습니다.

이 도구의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.
